Lists are dynamic and can hold heterogeneous  data types meaning a single list can 
contain a mix of of strings,integers,booleans and even other lists.

**Characteristics **
//////////////////
* Ordered:
 Items maintain their specific insertion order.

* Mutable:
Changable,elements can be added,modified,or removed after creation.

* Zero-Indexed:
first index starts at index 0

* Allows duplicates:
can have same value item for multiple times

** Methods **
.append(item)
Adds elements to the very end of the list

.insert(index,item)
insert an item at specified index.

.extend(iterable)
Appends elements from another collection or iterable. to the end

.remove(item)
Removes the first occurence of specified value of the item

.pop(index)
removes and returns the item at given index(default to the last item)

.sort()
sorts list items in place

.reverse()
reverse the order of the list
